## 💀 踩坑记录 · 做了但没做完的

### 💰 ledger · 自动记账本 `已搁置`
银行短信 / 支付画面**自动入账** · 差额红字一键补记 · 数据全本地(TSV)无云 · 密码节点永不读取

**为什么停在这**：PC 端能跑通，但 Android 端自动入账依赖「通知监听 + 无障碍」两个系统权限，真机适配的坑比预想深（各厂商 ROM 杀后台、权限入口不一致），做完 PC 端就搁置了。留着当踩坑记录。
